## 系統簡介 System Overview

### 關於員工排班系統 About the Scheduling System

員工排班系統是MakanMasak餐廳管理系統的核心模組之一，專為餐飲業設計，幫助管理者高效地安排員工工作時間，確保餐廳營運順暢。

The Employee Scheduling System is a core module of the MakanMasak Restaurant Management System, specifically designed for the food service industry to help managers efficiently arrange employee work schedules and ensure smooth restaurant operations.

## 班別模板管理 Shift Template Management

### 什麼是班別模板？ What is a Shift Template?

班別模板是可重複使用的班別設定，包含工作時間、休息時間、人力需求等資訊。創建模板後，可以快速套用到多個日期和員工。

A shift template is a reusable shift configuration that includes work hours, break times, and staffing requirements. Once created, templates can be quickly applied to multiple dates and employees.

### 編輯班別模板 Edit Shift Template

```
編輯模板流程 Edit Template Flow:

1. 在班別模板列表中找到要編輯的模板
   Find the template to edit in the template list

2. 點擊模板卡片右上角的「編輯」按鈕 (✏️ 圖標)
   Click the "Edit" button (✏️ icon) in template card

3. 修改所需欄位
   Modify desired fields

4. 點擊「儲存」保存更改
   Click "Save" to保存 changes

⚠️ 注意 Warning:
• 修改模板不會影響已排定的班表
  Template changes won't affect existing schedules
• 新排班將使用更新後的模板設定
  New schedules will use updated template settings
```

## 衝突處理 Conflict Resolution

### 衝突類型 Conflict Types

```
╔══════════════════════════════════════════════════╗
║            排班衝突類型說明                       ║
╠══════════════════════════════════════════════════╣
║                                                  ║
║  🔴 【嚴重衝突 Critical Conflicts】              ║
║     必須解決才能儲存排班                         ║
║                                                  ║
║  1. 時間重疊 Time Overlap                        ║
║     員工在同一時間有多個排班                     ║
║     範例: 09:00-17:00 和 14:00-22:00            ║
║                                                  ║
║  2. 請假衝突 Leave Conflict                      ║
║     員工在排班日期已申請並核准請假               ║
║     範例: 已核准 2025-11-15 病假                ║
║                                                  ║
║  3. 超時工作 Excessive Hours                     ║
║     超過勞基法規定的每日/每週工時上限           ║
║     範例: 每日工作超過 12 小時                  ║
║                                                  ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━            ║
║                                                  ║
║  🟡 【警告衝突 Warning Conflicts】               ║
║     建議解決但可強制儲存                         ║
║                                                  ║
║  4. 休息不足 Insufficient Rest                   ║
║     兩班之間休息時間少於 11 小時                ║
║     範例: 晚班 22:00 結束，早班 09:00 開始      ║
║                                                  ║
║  5. 連續工作 Continuous Work                     ║
║     連續工作天數超過 6 天                        ║
║     範例: 連續 7 天排班無休假                   ║
║                                                  ║
║  6. 人力不足 Understaffed                        ║
║     該班別的員工數少於最少需求                   ║
║     範例: 需要 3 人但只排了 2 人                ║
║                                                  ║
```

## 常見問題 FAQ

### Q1: 如何快速創建一週的排班？

```
A: 使用批量排班功能

步驟:
1. 點擊「批量排班」
2. 選擇日期範圍 (例如: 11/10 - 11/16)
3. 選擇班別模板
4. 選擇要排班的員工
5. 選擇適用的星期
6. 預覽並確認
7. 系統自動創建所有排班

💡 或者使用「複製上週」功能，
   一鍵複製上週的所有排班!
```

### Q2: 員工忘記打卡怎麼辦？

```
A: 可以補填打卡記錄

員工操作:
1. 進入「打卡管理」頁面
2. 點擊「補填打卡」
3. 選擇日期和時間
4. 填寫原因
5. 提交申請

管理者操作:
1. 收到補填申請通知
2. 查看申請詳情
3. 核對實際情況
4. 批准或拒絕申請
5. 系統自動更新打卡記錄

⚠️ 注意:
• 只能補填 7 天內的記錄
• 需要主管審核通過
• 補填記錄會特別標記
```

### Q3: 如何處理緊急換班？

```
A: 使用快速換班流程

緊急情況處理:
1. 員工提交換班申請
2. 標記為「🔴 緊急」
3. 系統優先通知
4. 對方快速回應
5. 管理者即時審批

💡 建議:
• 緊急情況先電話聯繫
• 同時提交線上申請
• 管理者可開啟「緊急通道」
  直接批准後事後補登記
```

```
✅ 請假衝突
✅ 人力需求

   選擇員工時立即顯示狀態

3. 使用「智能推薦」
   系統推薦最適合的員工

   及早發現潛在問題
```

### Q6: 如何設定員工的可用時段？

```
A: 在員工資料中設定

設定步驟:
1. 進入「員工管理」
2. 選擇員工
3. 點擊「可用性設定」
4. 設定每週可用時段:

   週一: 09:00-17:00 ✅ 優先
   週二: 09:00-22:00 ✅ 可用
   週三: 14:00-22:00 ⚠️  有限制
   週四: 全天不可用  ❌ 不可用
   週五: 09:00-17:00 ✅ 優先

5. 設定黑名單日期:
   • 2025-11-20: 私人行程
   • 2025-12-25: 家庭聚會

系統會在排班時:
• 優先推薦「優先」時段的員工
• 警告「有限制」時段
• 阻止「不可用」時段排班
```

### Q7: 可以限制員工的每週工時嗎？

```
A: 可以設定工時上限

設定位置:
1. 「系統設定」→「排班規則」
2. 設定全域規則:
   • 每日最大工時: 12 小時
   • 每週最大工時: 48 小時
   • 每月最大工時: 192 小時

3. 設定個別員工規則:
   • 可為特定員工設定不同上限
   • 兼職員工通常工時較少

系統會:
• 排班時自動計算已用工時
• 超過上限時顯示警告
• 可選擇強制執行或僅警告

💡 建議:
• 設定為勞基法規定的上限
• 定期檢查工時報表
• 及時調整員工負荷
```
