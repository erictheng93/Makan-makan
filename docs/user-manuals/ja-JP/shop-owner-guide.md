```
│  └──────────────┘    └──────────────┘                 │
│         ↓                    ↓                         │

│  └──────────────┘    └──────────────┘                 │
│         ↓                    ↓                         │
│  ┌──────────────┐    ┌──────────────┐                 │
│  │注文管理      │───→│スタッフ管理  │                 │

│         ↓                    ↓                         │
│  ┌──────────────┐    ┌──────────────┐                 │
│  │業務分析      │───→│AI分析        │                 │
│  └──────────────┘    └──────────────┘                 │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 複数役割協力モード

```
        オーナー (あなた)
           │
    ┌──────┼──────┬──────┐
    ↓      ↓      ↓      ↓
シェフ  配膳  会計  顧客
    │      │      │      │
    └──────┴──────┴──────┘
           │
   リアルタイム協力プラットフォーム
```

**説明**：

- **オーナー**：完全な管理権限、すべてのデータを閲覧可能
- **シェフ**：注文を受け取り、調理状況を更新
- **配膳スタッフ**：配膳を確認、注文進捗を更新
- **会計**：会計処理、売上確認
- **顧客**：QRコードをスキャンして注文、注文を追跡

## ⚙️ レストラン基本設定

### レストラン情報管理

移動：**ダッシュボード → レストラン設定 → 基本情報**

#### 必須情報

| 項目           | 説明                                 | 例                           |
| -------------- | ------------------------------------ | ---------------------------- |
| レストラン名   | 顧客側に表示される店名               | 美味シーフードレストラン     |
| レストラン住所 | 完全な住所（郵便番号を含む）         | 東京都千代田区丸の内1-1-1    |
| 連絡電話       | カスタマーサービスまたは予約専用回線 | 03-1234-5678                 |
| 営業時間       | 毎日の営業時間帯                     | 11:00-14:00, 17:00-21:00     |
| レストラン説明 | 紹介、特徴説明                       | 新鮮な海産物と伝統料理を提供 |

#### 営業時間設定

```
┌─────────────────────────────────────────┐
│ 営業時間設定例                          │
├─────────────────────────────────────────┤
│                                         │
│  月曜日 - 金曜日:                       │
│  ├─ ランチタイム: 11:00 - 14:00        │
│  └─ ディナータイム: 17:00 - 21:00      │
│                                         │
│  土曜日 - 日曜日:                       │
│  └─ 終日営業: 11:00 - 21:00            │
│                                         │
│  定休日: 毎週水曜日                     │
│                                         │
└─────────────────────────────────────────┘
```

### レストラン画像のアップロード

対応フォーマット：JPG、PNG、WebP
推奨サイズ：1920x1080 ピクセル
ファイルサイズ：最大 5MB

**アップロード手順**：

1. 「画像をアップロード」ボタンをクリック
2. レストランの外観または特徴的な料理の画像を選択
3. システムが自動的に圧縮し、複数のサイズを生成
4. プレビューを確認後、保存

```
     ↓
高速グローバル配信 (CDN)
```

### 料理の一括管理

#### 価格一括更新

移動：**メニュー管理 → 一括操作 → 価格調整**

使用シナリオ：

- 季節的な価格変更
- コスト上昇による調整
- プロモーション活動の設定

**操作手順**：

1. 調整する料理を選択（複数選択可）
2. 調整方法を設定：
   - 固定金額調整（例：+¥100）
   - パーセント調整（例：+5%）
3. 調整結果をプレビュー
4. 確認後適用

#### 一括有効化/無効化

クイック操作：

- ✅ 選択した料理を一括有効化
- ⏸️ 選択した料理を一括停止
- ❌ 選択した料理を一括無効化

### 座席管理（デュアルモード）

MakanMakanは2種類の座席管理モードをサポートしています：

#### モード1：テーブルレベルQRコード

```
┌─────────────────────────────────────┐
│  テーブル A1 (4人席)                │
│                                     │
│    [テーブル中央に1つのQRコード]   │
│                                     │
│  使用シナリオ：                     │
│  • テーブル全体で一緒に注文         │
│  • 家族での食事、友人との集まり     │
│  • 注文を一括会計                   │
│                                     │
└─────────────────────────────────────┘
```

#### モード2：座席レベルQRコード

```
┌─────────────────────────────────────┐
│  テーブル B1 (4人席)                │
│                                     │
│  [QR-1]     [QR-2]                 │
│    座席1      座席2                 │
│                                     │
│  [QR-3]     [QR-4]                 │
│    座席3      座席4                 │
│                                     │
│  使用シナリオ：                     │
│  • 個別注文、別会計                 │
│  • ファストフード、フードコート     │
│  • ビジネスランチ                   │
│                                     │
└─────────────────────────────────────┘
```

#### モード選択ガイド

| 経営形態         | 推奨モード     | 理由                                           |
| ---------------- | -------------- | ---------------------------------------------- |
| 伝統的レストラン | テーブルレベル | 通常テーブル全体で食事                         |
| 鍋料理店         | テーブルレベル | 鍋を共有、一括注文                             |
| ファストフード店 | 座席レベル     | 個人注文、高速回転                             |
| フードコート     | 座席レベル     | 見知らぬ人同士の相席、独立会計                 |
| カフェ           | 混合           | 大テーブルはテーブルレベル、個人席は座席レベル |

### 座席の作成

移動：**テーブル管理 → テーブルを選択 → 座席設定**

**座席の一括作成**：

```
テーブルを選択 → 座席数を設定 → 番号を自動生成
                              ↓
                    座席1, 座席2, 座席3, 座席4
                              ↓
                      システムが自動でQRコード生成
```

## 📱 QRコードシステム

### 3種類のQRコードモード

MakanMakanは、異なる経営シナリオに適応する3種類のQRコード使用モードを提供します：

```
┌─────────────────────────────────────────────────────┐
│ QRコードシステム構造                                │
├─────────────────────────────────────────────────────┤
│                                                     │
│  モード1: 店舗レベルQR                             │
│  ┌──────────────────────────────┐                 │
│  │  1つのQRコード → レストラン全体│                 │
│  │  適用：テイクアウト、配達、    │                 │
│  │       テーブルなし             │                 │
│  └──────────────────────────────┘                 │
│                 │                                   │
│  モード2: テーブルレベルQR                         │
│  ┌──────────────────────────────┐                 │
│  │  テーブルごとに1つのQRコード  │                 │
│  │  適用：伝統的な店内レストラン  │                 │
│  └──────────────────────────────┘                 │
│                 │                                   │
│  モード3: 座席レベルQR                             │
│  ┌──────────────────────────────┐                 │
│  │  各座席に独立したQRコード      │                 │
│  │  適用：個人注文、別会計        │                 │
│  └──────────────────────────────┘                 │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### モード1：店舗レベルQRコード

**使用シナリオ**：

- ✅ テイクアウト/配達店舗
- ✅ 座席なし（立ち食い、屋台）
- ✅ キッチンカー
- ✅ ポップアップストア、マーケット屋台

**生成方法**：

移動：**QRコード管理 → 店舗QR → 店舗QRコード生成**

```
┌─────────────────────────────────────┐
│ 店舗QRコード設定                    │
├─────────────────────────────────────┤
│                                     │
│  QRコードタイプ: 店舗レベル         │
│  使用方法: 顧客がスキャン後に       │
│           直接メニューに入る        │
│                                     │
│  掲示位置の提案:                    │
│  ├─ 店頭ポスター                   │
│  ├─ レジ前                         │
│  ├─ SNS共有                        │
│  └─ 配達プラットフォームリンク     │
│                                     │
│  [QRコード生成]  [画像ダウンロード]│
│                                     │
└─────────────────────────────────────┘
```

**顧客注文フロー**：

```
店舗QRをスキャン
     ↓
メニューに入る
     ↓
料理を選択
     ↓
受取情報を記入
     ↓
注文を確認
     ↓
受取通知を待つ
```

### モード2：テーブルレベルQRコード

**使用シナリオ**：

- ✅ 伝統的なレストラン店内
- ✅ テーブル全体で共同注文
- ✅ 家族、友人との食事
- ✅ 一括会計モード

**生成方法**：

移動：**テーブル管理 → テーブルを選択 → QRコード生成**

```
┌─────────────────────────────────────┐
│ テーブルQRコード設定                │
├─────────────────────────────────────┤
│                                     │
│  テーブル番号: A1                   │
│  QRコードタイプ: テーブルレベル     │
│                                     │
│  設定オプション:                    │
│  □ 追加注文を許可                  │
│  □ テーブル情報を表示              │
│  □ テーブル番号を自動入力          │
│                                     │
│  [単一QR生成]  [一括生成]          │
│                                     │
└─────────────────────────────────────┘
```

**テーブルQRの一括生成**：

```
複数のテーブルを選択
     ↓
統一パラメータを設定
     ↓
すべてのQRコードを一括生成
     ↓
ZIPファイルをダウンロード
     ↓
解凍後印刷して貼り付け
```

**顧客注文フロー**：

```
着席 → テーブル上のQRをスキャン
          ↓
     注文ページに入る
     (テーブル番号を自動入力)
          ↓
     料理を選択
          ↓
     注文を送信
          ↓
     配膳を待つ
```

### モード3：座席レベルQRコード

**使用シナリオ**：

- ✅ ファストフード店、フードコート
- ✅ ビジネスランチ
- ✅ 見知らぬ人同士の相席
- ✅ 個別注文、別会計

**生成方法**：

移動：**テーブル管理 → テーブルを選択 → 座席管理 → 座席QRを一括生成**

```
┌─────────────────────────────────────┐
│ 座席QR一括生成                      │
├─────────────────────────────────────┤
│                                     │
│  テーブル: A1                       │
│  座席数: [4]                        │
│                                     │
│  座席番号自動生成:                  │
│  ├─ A1-座席1                       │
│  ├─ A1-座席2                       │
```

## ❓ よくある質問

### システム使用関連

**Q1: 初期パスワードを忘れた場合はどうすればよいですか？**

A: パスワードリセット機能を使用してください：

1. ログインページで「パスワードを忘れた」をクリック
2. 登録済みメールアドレスを入力
3. メールで受信したリンクをクリック
4. 新しいパスワードを設定

**Q2: スタッフのログイン情報を確認できますか？**

A: はい、できます：

- 移動：**スタッフ管理 → スタッフリスト**
- 該当スタッフの「編集」をクリック
- 「パスワードをリセット」で新しい一時パスワードを生成

**Q3: システムにアクセスできない場合は？**

A: 以下を確認してください：

- インターネット接続が安定しているか
- ブラウザのキャッシュをクリア
- 異なるブラウザで試す
- それでも解決しない場合は技術サポートに連絡

### メニュー管理関連

**Q4: 料理の一時的な品切れを設定するには？**

A: クイック操作手順：

1. **メニュー管理 → 料理リスト**に移動
2. 該当料理を見つける
3. 状態を「⏸️ 一時的に品切れ」に変更
4. 保存すると、顧客側のメニューから自動的に非表示

**Q5: 複数の料理の価格を一度に変更できますか？**

A: はい、一括価格調整機能があります：

1. **メニュー管理 → 一括操作**に移動
2. 調整する料理を複数選択
3. 調整方法を選択（固定金額または パーセント）
4. プレビュー後、適用

**Q6: 料理の画像を変更するには？**

A: 手順：

1. **メニュー管理 → 料理リスト**
2. 該当料理の「編集」
3. 画像エリアで「画像を変更」をクリック
4. 新しい画像をアップロード
5. 保存

### 注文処理関連

**Q7: 注文を誤って受け付けた場合はどうすればよいですか？**

A: 注文キャンセル手順：

1. **注文管理 → 注文を検索**
2. 該当注文の詳細を開く
3. 「注文をキャンセル」をクリック
4. キャンセル理由を記入
5. 確認（システムが自動的に顧客に通知）

**Q8: 顧客が注文内容の変更を要求した場合は？**

A: 2つの方法：

- **方法1**（推奨）: 顧客に追加注文機能で新しい注文を送信してもらう
- **方法2**: 店舗側で元の注文をキャンセルし、顧客に再注文を依頼

**Q9: 注文通知を受け取れない場合は？**

A: トラブルシューティング：

1. **設定 → 通知設定**を確認
2. ブラウザの通知権限を確認
3. 音声通知が有効になっているか確認
4. ページを更新してみる

### QRコード関連

**Q10: QRコードが機能しない場合は？**

A: 確認事項：

1. QRコードが破損していないか（再印刷を検討）
2. 正しいテーブル/座席にリンクしているか
3. QRコードが有効化されているか
4. 問題が継続する場合は、QRコードを再生成

**Q11: QRコードのデザインをカスタマイズできますか？**

A: はい、できます：

- **QRコード管理 → デザインテンプレート**に移動
- 既存のテンプレートを選択または新規作成
- レストランのロゴとブランドカラーを追加
- カスタムテキストやアイコンを挿入

**Q12: 複数のテーブルのQRコードを一度に印刷するには？**

A: 一括印刷機能：

1. **テーブル管理 → 一括操作**
2. 印刷するテーブルを選択
3. 「QRコードを一括生成」
4. ZIPファイルをダウンロード
5. 解凍して一括印刷

### レポートと分析関連

**Q13: 特定期間の売上レポートを取得するには？**

A: カスタムレポート生成：

1. **業務分析 → 売上レポート**に移動
2. 日付範囲を設定
3. フィルター条件を選択（カテゴリー、時間帯など）
4. 「レポートを生成」
5. PDF/Excelでエクスポート可能

**Q14: AI分析の信頼度はどのくらいですか？**

A: AI分析の信頼度について：

- 一般的な信頼度: 85-95%
- 信頼度はデータ量と質に依存
- 1ヶ月以上の運営データがあると精度が向上
- 推奨アクションは参考として使用し、最終判断はオーナー自身で

**Q15: レポートデータを会計システムにエクスポートできますか？**

A: はい、複数のフォーマットに対応：

- Excel (.xlsx)
- CSV (.csv)
- PDF (印刷用)
- JSON (API統合用)

### トラブルシューティング

**Q16: システムが遅い場合は？**

A: パフォーマンス改善手順：

1. ブラウザのキャッシュをクリア
2. 不要なブラウザタブを閉じる
3. ブラウザを再起動
4. 最新バージョンのブラウザを使用
5. 問題が継続する場合は技術サポートに連絡

**Q17: データのバックアップはどうなっていますか？**

A: データ保護：

- 自動バックアップ: 毎日実行
- データ保持期間: 90日
- 災害復旧: 24時間以内
- データは暗号化されて安全に保存

**Q18: システムアップデート時にサービスは停止しますか？**

A: いいえ、停止しません：

- アップデートは無停止で実行
- メンテナンスは深夜時間帯（通常 2:00-4:00）
- 事前に通知メールを送信
- 緊急メンテナンスの場合は即座に通知
