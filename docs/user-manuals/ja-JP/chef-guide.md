## 🚀 クイックスタート

### シェフの核心職責

```
┌─────────────────────────────────────────────┐
│ シェフ業務フロー                            │
├─────────────────────────────────────────────┤
│                                             │
│  1️⃣ 新規注文を受信                        │
│      ↓                                      │
│  2️⃣ 注文内容を確認                        │
│      ↓                                      │
│  3️⃣ 「調理中」に更新                      │
│      ↓                                      │
│  4️⃣ 調理を開始                            │
│      ↓                                      │
│  5️⃣ 完了後「完成」に更新                  │
│      ↓                                      │
│  6️⃣ 配膳スタッフに通知                    │
│                                             │
└─────────────────────────────────────────────┘
```

### 初回使用チェックリスト

✅ **ステップ1：アカウントと機器の確認**
- シェフアカウントの取得を確認
- キッチンディスプレイシステムへのログインテスト
- ディスプレイ画面が正常に表示されることを確認

✅ **ステップ2：インターフェースに慣れる**
- 注文カードレイアウトを理解
- 状態更新操作を練習
- 音声通知をテスト

✅ **ステップ3：フローを理解**
- 新規注文通知方法
- 状態更新手順
- 注文完了フロー

✅ **ステップ4：準備作業**
- キッチン設備が準備完了していることを確認
- 食材の下ごしらえを確認
- 注文受付を開始

## 🏢 システム概要

### キッチンディスプレイシステムの位置づけ

```
┌─────────────────────────────────────────────────────────┐
│ MakanMakan キッチンエコシステム                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  顧客注文 ───→ 注文システム ───→ キッチン表示 ───→ 配膳確認│
│                     ↓              ↓              ↓     │
│                 オーナー監視    【ここにいます】  顧客追跡│
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### キッチン役割協力モード

```
        注文ソース
           │
    ┌──────┴──────┐
    ↓             ↓
テーブル注文    店舗注文
    │             │
    └──────┬──────┘
           ↓
  【キッチンディスプレイシステム】
       (あなたのワークステーション)
           │
    ┌──────┴──────┐
    ↓             ↓
配膳スタッフ    顧客側
配達確認      リアルタイム追跡
```

**説明**：
- **顧客**：QRコードで注文
- **キッチンシステム**：リアルタイムで注文を受信・表示
- **シェフ（あなた）**：注文を処理し、状態を更新
- **配膳スタッフ**：料理を取り、顧客に配膳
- **オーナー**：全体の運営状況を監視

### 状態更新操作

**「調理中」に更新**

調理を開始する準備ができたら：

```
┌─────────────────────────┐
│ #025 - 7番テーブル      │
├─────────────────────────┤
│ • シーフード炒飯 x1     │
│ • 酸辣湯 x2             │
│                         │
│ [✋ 調理開始]           │  ← このボタンをクリック
└─────────────────────────┘

クリック後 ↓

┌─────────────────────────┐
│ #025 - 7番テーブル ⏱️ 3:25│
├─────────────────────────┤
│ • シーフード炒飯 x1     │
│ • 酸辣湯 x2             │
│                         │
│ [✓ 調理完了]           │  ← 状態が更新されました
└─────────────────────────┘
```

**「完成」に更新**

料理の調理が完了したら：

```
調理中 → 完成

操作手順:
1. すべての品目が完成したことを確認
2. 品質と外観を確認
3. 「調理完了」ボタンをクリック
4. カードが「完成」欄に移動
5. システムが自動的に配膳スタッフに通知
```

### 一括操作機能

**複数の注文を一度に処理**

複数の注文を同時に調理できる場合：

```
一括選択モード:

☐ #023 - 炒飯 x2
☑ #024 - 炒飯 x1, 炒麵 x1
☑ #025 - 炒飯 x3

[同類を全選択] [調理開始 (2)]
               ↑
           2つの注文を選択済み

メリット:
✓ 調理時間を節約
✓ キッチン効率を向上
✓ 同時提供でより速く
```

## ❓ よくある質問

### システム使用関連

**Q1: ログインパスワードを忘れた場合は？**

A: オーナーまたは管理者に連絡して、パスワードをリセットしてもらってください。セキュリティ上の理由から、シェフ自身でパスワードをリセットすることはできません。

**Q2: 注文通知音が聞こえない場合は？**

A: 以下を確認してください：
1. 右上の設定アイコン ⚙️ をクリック
2. 音声設定を確認
3. 音量が適切なレベルに設定されているか確認
4. ブラウザの音声権限が有効になっているか確認

**Q3: システムが動かない場合は？**

A: トラブルシューティング手順：
1. ページを更新（F5キー）
2. ネットワーク接続を確認
3. ログアウトして再ログイン
4. それでも解決しない場合はオーナーに報告

### 注文処理関連

**Q4: 調理を開始した後に注文をキャンセルする必要がある場合は？**

A: 即座にオーナーまたは会計に連絡してください。彼らが注文をキャンセルし、顧客に通知します。すでに調理した料理についてはオーナーが対処方法を決定します。

**Q5: 顧客の特別要望（アレルギーなど）を見逃した場合は？**

A: 料理を提供する前に気づいた場合：
- 即座に作り直す
- 絶対に隠さないでください
- オーナーに報告

提供後に気づいた場合：
- 即座にオーナーと配膳スタッフに通知
- 顧客の安全が最優先

**Q6: 複数の緊急注文がある場合、どれを先に処理すべきですか？**

A: 優先順位の判断：
1. 🔴 最長待機時間（15分以上）
2. 🟠 VIP顧客または大テーブル
3. 🟡 調理時間が短い料理（すぐに完成）
4. 🟢 通常の順序

システムが自動的に最も緊急な注文を強調表示します。

### 食材と設備関連

**Q7: 食材が不足している場合は？**

A: 即座の対応：
1. 注文カードで「問題報告」をクリック
2. 「食材不足」を選択
3. 不足している品目を記入
4. システムがオーナーに自動通知
5. オーナーの指示を待つ

代替案を提案できる場合は、メモに記載してください。

**Q8: 調理中に設備が故障した場合は？**

A: 緊急対応手順：
1. 即座に調理を停止（安全第一）
2. オーナーに緊急連絡
3. 他の設備で代替できるか確認
4. 進行中の注文への影響を評価
5. 顧客に影響がある場合、オーナーが通知

**Q9: 食材の品質に疑問がある場合は？**

A: 絶対にルール：
- 疑わしい食材は使用しない
- オーナーまたはキッチンマネージャーに報告
- 顧客の安全が最優先
- 記録のため写真を撮る

### チーム協力関連

**Q10: 配膳スタッフが料理を取りに来ない場合は？**

A: 手順：
1. 完成から3分経過したか確認
2. 配膳スタッフシステムで通知を確認
3. 直接呼びかけるかメッセージを送信
4. それでも来ない場合はオーナーに報告

料理の温度と品質を維持することを忘れないでください。

**Q11: 他のシェフとの作業調整方法は？**

A: 効果的な協力：
- 明確にコミュニケーション
- 誰が何の注文を担当しているか確認
- 重複調理を避ける
- ヘッドシェフがいる場合は彼らの調整に従う
- 繁忙時は互いにサポート

**Q12: クレーム後に作り直す場合は？**

A: 品質保証手順：
1. 元の問題を理解する
2. すべての特別要望を再確認
3. 調理品質を二重確認
4. ヘッドシェフまたはオーナーに最終確認を依頼
