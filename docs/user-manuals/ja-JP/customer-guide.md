## 🎉 MakanMasakへようこそ

MakanMasakは、スマートフォンでメニューの閲覧、注文、リアルタイムでの注文状況確認ができる、モダンなスマートオーダリングプラットフォームです。アプリのダウンロードは不要 - QRコードをスキャンするだけで始められます！

### ✨ 主な特徴

- 📱 **アプリ不要** - モバイルブラウザから直接利用可能
- 🎯 **シンプル & 高速** - QRコードをスキャンして注文
- 📊 **リアルタイム追跡** - いつでも注文状況を確認
- 💾 **オフライン対応** - ネット環境が不安定でも動作
- 👤 **会員システム** - 登録後、注文履歴の確認が可能
- 🌐 **多言語対応** - 繁体字中国語、英語、ベトナム語、インドネシア語、フィリピン語、日本語

## 🍽️ 注文方法

MakanMasakは、レストランの設定に応じて2つの注文方法を提供しています：

### 方法1：テーブルQRコード注文

**利用シーン**: 固定席のある店内飲食レストラン

#### 📍 使い方

1. **テーブルのQRコードを探す**
   - 通常、テーブル、テーブルスタンド、または食器に配置
   - 各テーブルには固有のQRコードがあります

2. **QRコードをスキャン**

   ```
   方法1: スマホのカメラアプリを使用
   └─ カメラを開いてQRコードに向ける
   └─ 表示されたリンク通知をタップ

   方法2: LINE/WeChatのスキャナーを使用
   └─ スキャン機能を開く
   └─ QRコードに向ける
   ```

3. **注文を開始**
   - スキャン後、メニューページが自動的に開きます
   - ご注文はこのテーブルに紐付けられます
   - 登録不要で注文可能

#### 🎯 特徴

- ✅ 登録なしで直接注文
- ✅ 注文が自動的にキッチンに送信
- ✅ スタッフがテーブル番号を確認可能
- ✅ 追加注文可能（再度スキャン）

---

### 方法2：店舗QRコード注文

**利用シーン**: テイクアウトカウンター、屋台、ポップアップストア、フードトラック

#### 📍 使い方

1. **店舗QRコードをスキャン**
   - 通常、カウンターまたは店頭に配置
   - 店舗全体で1つのQRコード

2. **電話番号確認が必要（初回のみ）**

   **ステップ1: 電話番号を入力**

   ```
   ┌──────────────────────────┐
   │  電話番号を入力          │
   │  ┌────────────────────┐  │
   │  │ +81 90-1234-5678   │  │
   │  └────────────────────┘  │
   │                          │
   │  [確認]                  │
   └──────────────────────────┘
   ```

   - 国番号付きで電話番号を入力
   - 例：日本 +81、マレーシア +60

   **ステップ2: 認証コードを入力（オプション）**
   - 一部のレストランでは電話確認が必要
   - SMSで6桁のコードを受信
   - コードを入力して認証を完了

3. **注文を開始**
   - 認証後、メニューを閲覧
   - カートに追加して注文を送信

4. **商品の受け取り**
   - 注文には電話番号の下4桁が表示されます
   - スタッフが番号で呼び出します
   - 例：「5678番のお客様、ご注文の品ができました！」

#### 🎯 特徴

- ✅ テイクアウトに最適
- ✅ 電話番号が受取番号に
- ✅ 注文状況の確認可能
- ✅ 事前注文対応

## 👤 会員機能

登録してさらに多くの機能をご利用ください！

### 新規登録

#### 📝 登録手順

1. **登録ページへ移動**
   - ホームページの「登録」をクリック
   - またはログインページの「今すぐ登録」をクリック

2. **登録フォームに記入**

   ```
   ┌────────────────────────────────┐
   │  会員登録                      │
   │                                │
   │  氏名                          │
   │  ┌──────────────────────────┐  │
   │  │ 山田 太郎                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  電話番号                      │
   │  ┌──────────────────────────┐  │
   │  │ +81 90-1234-5678         │  │
   │  └──────────────────────────┘  │
   │                                │
   │  メール（任意）                │
   │  ┌──────────────────────────┐  │
   │  │ yamada@example.com       │  │
   │  └──────────────────────────┘  │
   │                                │
   │  パスワード                    │
   │  ┌──────────────────────────┐  │
   │  │ ••••••••                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  パスワード確認                │
   │  ┌──────────────────────────┐  │
   │  │ ••••••••                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  [登録]                        │
   └────────────────────────────────┘
   ```

3. **登録完了**
   - 「登録」ボタンをクリック
   - システムが自動的にログイン

#### ⚠️ 重要事項

- 電話番号は必須（ログインIDとして使用）
- パスワードは8文字以上
- メールは任意（パスワードリセット用）

#### 🔐 ログイン手順

1. **ログインページへ移動**
   - ホームページの「ログイン」をクリック

2. **認証情報を入力**

   ```
   ┌────────────────────────────────┐
   │  会員ログイン                  │
   │                                │
   │  電話番号                      │
   │  ┌──────────────────────────┐  │
   │  │ +81 90-1234-5678         │  │

   │  │ ••••••••                 │  │
   │  └──────────────────────────┘  │
   │                                │
   │  [ログイン]                    │
   │                                │
   │  パスワードを忘れた? | 登録    │
   └────────────────────────────────┘
   ```

3. **ログイン成功**
   - 注文ページへ自動移動
   - または前のページに戻る

#### 💡 ヒント

- ログイン状態を保持すると注文追跡が簡単
- パスワードを忘れた場合は「パスワードを忘れた？」をクリックしてリセット

### 注文履歴

会員はすべての過去の注文を確認できます。

#### 📜 確認方法

1. 会員アカウントにログイン
2. 「プロフィール」へ移動
3. 「注文履歴」をクリック

#### 📊 注文情報

各注文には以下が表示されます：

```
┌────────────────────────────────────┐
│  注文 #12345                       │
│  ────────────────────────────      │
│                                    │
│  📅 2025-10-26 14:30              │
│  🏪 美味しいレストラン             │
│  🪑 テーブル: A12                  │
│  💰 合計: ¥3,500                   │
│  📌 ステータス: 完了               │
│                                    │
│  注文内容:                         │
│  • ラーメン x 1  ¥1,500           │
│  • 餃子 x 2  ¥1,000               │
│  • ビール x 2  ¥1,000             │
│                                    │
│  [詳細を見る]                      │
└────────────────────────────────────┘
```

#### 🔍 注文ステータスの説明

| ステータス    | 説明                     |
| ------------- | ------------------------ |
| 🟡 確認待ち   | 注文送信済み、確認待ち   |
| 🔵 調理中     | レストランが受付、調理中 |
| 🟢 完了       | 注文完了                 |
| 🔴 キャンセル | 注文キャンセル           |

#### ➕ 基本手順

1. **料理カードをクリック**
   - 詳細情報が表示されます

2. **料理の詳細を確認**

   ```
   ┌────────────────────────────────┐
   │  ラーメン                      │
   │  ──────────────────────        │
   │                                │
   │  [大きな画像]                  │

   │                                │

   │                                │
   │  🎛️ カスタマイズ:              │
   │  • 辛さ: □ なし □ 少し ☑ 普通  │
   │  • 麺: ☑ 太麺 □ 細麺           │
   │  • トッピング: □ なし ☑ 卵 (+¥100)│
   │                                │
   │  🔢 数量: - [1] +              │
   │                                │
   │  💬 備考:                      │
   │  ┌──────────────────────────┐  │
   │  │ ネギ抜きでお願いします   │  │
   │  └──────────────────────────┘  │
   │                                │
   │  [カートに追加 ¥1,600]         │
   └────────────────────────────────┘
   ```

3. **カスタマイズを選択**（利用可能な場合）
   - 辛さ、甘さレベル
   - 食材の選択
   - トッピング

4. **数量を調整**
   - - または + ボタンをクリック
   - または直接数字を入力

5. **備考を追加**（任意）
   - 例：「ネギ抜き」「氷少なめ」「別包装」

6. **カートに追加**
   - 「カートに追加」ボタンをクリック
   - 成功メッセージが表示されます

#### 💡 ヒント

- 一度に複数の数量を追加可能
- 備考欄でキッチンに特別な要望を伝えられます
- トッピングの料金は自動計算

### カートを編集

1. **数量を調整**
   - - をクリックして減らす

2. **商品を削除**
   - ゴミ箱アイコンをクリック
   - 削除を確認

3. **買い物を続ける**
   - 「買い物を続ける」をクリックしてメニューに戻る
   - カートの内容は保存されます

   - 「カートをクリア」をクリック
   - すべての商品が削除されます

### 注文を送信

#### 📤 送信手順

1. **注文内容を確認**
   - すべての商品と数量を確認
   - 合計金額が正しいことを確認

2. **注文メモを追加**（任意）
   - 例：「お早めに」「別包装」

3. **「注文する」をクリック**
   - システムが注文情報を確認

4. **送信を確認**

   ```
   ┌────────────────────────────────┐
   │  ⚠️ 注文を確定しますか？       │
   │                                │
   │  送信後、注文内容の変更は      │
   │  できません。                  │
   │                                │
   │  合計: ¥3,410                  │
   │                                │
   │  [キャンセル]  [確定]          │
   └────────────────────────────────┘
   ```

5. **注文送信完了**
   - 注文番号が表示されます
   - 自動的に追跡ページへ移動

#### ⚠️ 重要な注意事項

- ⚠️ 送信後の変更・キャンセル不可
- ⚠️ 送信前に内容をご確認ください
- ⚠️ エラーがある場合はスタッフにお知らせください

## ❓ よくある質問

### 🤔 一般的な使用方法

**Q1: アプリのダウンロードは必要ですか？**
A: 不要です！モバイルブラウザでQRコードをスキャンするだけで利用できます。

**Q2: 注文するには登録が必要ですか？**
A: 必須ではありません。テーブル注文は登録なしで可能です。ただし、登録すると注文履歴を確認できます。

**Q3: 認証コードが届きません**
A: 以下を確認してください：

- 電話番号が正しいか
- SMSがスパムでブロックされていないか
- ネット接続が安定しているか
- スタッフにサポートを依頼

**Q4: 2つのテーブルから同時に注文できますか？**
A: 推奨しません。各テーブルには固有のQRコードがあるため、別々にスキャンしてください。

**Q5: 送信後にキャンセルできますか？**
A: システム上でのキャンセルはできません。すぐにスタッフにお知らせください。

---

### 🛒 ショッピングカート

**Q6: カートに時間制限はありますか？**
A: 24時間保存されます。タイムアウト後にクリアされる場合があります。

**Q7: 一部の料理がカートに追加できないのはなぜ？**
A: 以下の理由が考えられます：

- 一時的に売り切れ
- 提供時間外
- システムメンテナンス中

**Q8: 複数のレストランから同時に注文できますか？**
A: できません。1つのカートには1つのレストランの商品のみ入れられます。

---

### 💰 お支払い

**Q9: 支払い方法は？**
A: 現在、現地払いのみです。食事後にカウンターでお支払いください。

**Q10: クレジットカードやモバイル決済は使えますか？**
A: レストランのポリシーによります。スタッフにご確認ください。

---

### 📱 技術関連

**Q11: ページの読み込みが遅いのはなぜ？**
A: 以下の理由が考えられます：

- ネット信号が弱い
- スマホのメモリ不足
- ページを更新してみてください

**Q12: オフラインでも使えますか？**
A: 読み込み済みのメニューは閲覧できますが、注文送信にはインターネット接続が必要です。

**Q13: 対応しているブラウザは？**
A: 推奨：

- Safari（iOS）
- Chrome（Android）
- その他のモダンブラウザ

**Q14: パソコンで使えますか？**
A: 使えますが、モバイル向けに最適化されています。スマホでの利用を推奨します。

---

### 🔐 アカウント

**Q15: パスワードを忘れました**
A: ログインページの「パスワードを忘れた？」をクリックし、登録済みメールでリセットしてください。

**Q16: 電話番号を変更できますか？**
A: 現在サポートしていません。カスタマーサービスにお問い合わせください。

**Q17: アカウントを削除できますか？**
A: カスタマーサービスにアカウント削除を依頼してください。

### ブラウザキャッシュのクリア

ページに異常がある場合、キャッシュのクリアをお試しください：

**iOS Safari:**

1. 「設定」→「Safari」へ移動
2. 「履歴とWebサイトデータを消去」をタップ
3. クリアを確認

**Android Chrome:**

1. 右上のメニュー（三点）をタップ
2. 「設定」→「プライバシー」へ移動
3. 「閲覧データを削除」をタップ
4. 「キャッシュされた画像とファイル」を選択
5. 「データを削除」をタップ
