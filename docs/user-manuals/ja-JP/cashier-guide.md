### 毎日の開業チェックリスト

✅ **営業開始前**

- [ ] 会計システムにログイン
- [ ] レジの予備金額を確認
- [ ] レシート用紙が十分にあることを確認
- [ ] ネットワーク接続が正常であることを確認
- [ ] 本日の営業目標を確認

✅ **営業期間中**

- [ ] 会計待ち注文を常に注視
- [ ] レジを整頓された状態に保つ
- [ ] 定期的にレジの動作を確認
- [ ] 異常取引アラートに注意

✅ **営業終了後**

- [ ] 毎日の決算を実行
- [ ] 現金を数え、実際の金額と照合
- [ ] 日次決算レポートを印刷
- [ ] 現金を金庫に預ける
- [ ] システムからログアウト

## 🧾 注文会計フロー

### 標準会計手順

#### ステップ1：注文を照会

**方法1：テーブル番号照会**

```
1. 「クイック検索」をクリック
2. テーブル番号を入力（例：A1、B3）
3. システムがそのテーブルのすべての未会計注文を表示
4. 顧客の注文であることを確認
```

**方法2：注文番号照会**

```
1. 顧客に注文番号を尋ねる
2. 注文番号を入力
3. システムが注文詳細を表示
4. 注文内容を確認
```

**方法3：電話番号照会**

```
1. 顧客が会員かどうか尋ねる
2. 顧客の電話番号を入力
3. システムがその会員の未会計注文をリスト表示
4. 顧客に会計する注文を確認してもらう
```

#### ステップ4：支払い処理

**現金支払いフロー：**

```
1️⃣ 顧客に合計金額を伝える
   「こんにちは、合計5,610円です」

2️⃣ 現金を受け取る
   顧客が支払い：¥10,000

3️⃣ 実際に受け取った金額を入力
   システムが自動的におつりを計算：¥4,390

4️⃣ 金額が正しいことを確認後「支払い完了」をクリック

5️⃣ おつりを準備
   - 4,000円：1万円札1枚
   -   300円：100円玉3枚
   -    90円：50円玉1枚、10円玉4枚

6️⃣ おつりの金額を復唱
   「4,390円のおつりです、ありがとうございました」
```

**クレジットカード支払いフロー：**

```
1️⃣ 「クレジットカード」支払いを選択
2️⃣ 支払い金額を入力：¥5,610
3️⃣ クレジットカードを挿入/タッチ
4️⃣ 承認待ち...
5️⃣ 顧客にパスワード入力/サインを依頼
6️⃣ 取引成功 ✅
7️⃣ サイン伝票を印刷（サインが必要）
8️⃣ 顧客にサインを確認してもらう
9️⃣ サイン伝票を保管
```

**モバイル決済フロー：**

```
1️⃣ 「モバイル決済」を選択
2️⃣ 決済プラットフォームを選択
   ├─ PayPay
   ├─ LINE Pay
   ├─ 楽天Pay
   └─ その他

3️⃣ 支払い金額を入力：¥5,610
4️⃣ QRコードを表示またはスキャン
5️⃣ 顧客が携帯で支払いを確認
6️⃣ 支払い成功 ✅
7️⃣ 領収書を印刷
```

## 💳 支払い方法処理

### 現金支払い

**おつりの準備方法：**

```
┌─────────────────────────────────────────┐
│ おつり計算の例                          │
├─────────────────────────────────────────┤
│                                         │
│  合計金額: ¥5,610                       │
│  顧客支払い: ¥10,000                    │
│  おつり: ¥4,390                         │
│                                         │
│  紙幣の準備:                            │
│  ├─ ¥1,000 x 4 = ¥4,000                │
│  └─ 小計: ¥4,000                        │
│                                         │
│  硬貨の準備:                            │
│  ├─ ¥100 x 3 = ¥300                    │
│  ├─ ¥50 x 1 = ¥50                      │
│  ├─ ¥10 x 4 = ¥40                      │
│  └─ 小計: ¥390                          │
│                                         │
│  合計確認: ¥4,390 ✅                    │
│                                         │
└─────────────────────────────────────────┘
```

**現金処理のベストプラクティス：**

```
✅ すべきこと:
  • 顧客の前で現金を数える
  • おつりの金額を復唱
  • 領収書と一緒に渡す
  • 「ありがとうございました」と言う

❌ 避けるべきこと:
  • おつりを隠して数える
  • 急いで正確性を犠牲にする
  • おつりを投げて渡す
  • 顧客が去る前に確認しない
```

### 領収書再発行

**再発行が必要な場合：**

```
状況:
  ├─ 顧客が紛失
  ├─ 領収書が破損
  ├─ 印刷品質が悪い
  └─ 情報が間違っている

手順:
  1. 元の注文番号を検索
  2. 注文詳細を確認
  3. 「領収書再発行」を選択
  4. 再発行理由を記録
  5. 新しい領収書を印刷
  6. 「複製」マークが自動的に追加される
  7. 顧客に渡す
  8. 元の領収書（ある場合）を回収して破棄
```

## ❓ よくある質問

### システム操作

**Q1: システムがフリーズした場合は？**

A: トラブルシューティング手順：

1. 5秒待って自動回復を確認
2. 現在の取引状態を記録
3. システムを再起動
4. 再ログイン
5. 取引を再開または再処理
6. 技術的問題を報告

**Q2: レシート用紙を交換する方法は？**

A: 手順：

1. 新しいロールを準備
2. レジカバーを開ける
3. 古いロールを取り外す
4. 新しいロールを挿入（正しい向きで）
5. 用紙をガイドに通す
6. テスト印刷
7. カバーを閉める

**Q3: カード取引を取り消す方法は？**

A: 同日取り消し：

1. 「取引履歴」に移動
2. 取り消す取引を見つける
3. 「取り消し」を選択
4. 理由を入力
5. 顧客に身分証明書の提示を依頼
6. 取り消しを確認
7. 取り消しレシートを印刷

別日取り消し：

1. 手動返金処理が必要
2. マネージャーの承認を取得
3. 返金フローに従う

### 現金処理

**Q4: おつりが不足している場合は？**

A: 即座の対応：

1. 即座にマネージャーに通知
2. 近くのレジから借りる
3. 必要に応じて大きな紙幣を両替
4. 取引を文書化
5. シフト終了時に返却
6. 借入記録を保管

**Q5: 偽造紙幣を受け取った疑いがある場合は？**

A: 重要な手順：

1. 落ち着いて
2. 紙幣を受け取らない
3. 丁寧に顧客に伝える
4. マネージャーをすぐに呼ぶ
5. 別の支払い方法を依頼
6. 紛争を避ける
7. インシデントを文書化

**Q6: レジの過不足がある場合は？**

A: 決算手順：

1. 現金を再カウント
2. 小さな差異（±¥100）：記録して続行
3. 大きな差異（>¥100）：
   - マネージャーに報告
   - 可能な原因を確認
   - 差異フォームに記入
   - 調査のため文書化
4. パターンを追跡
5. 改善のためにフィードバック

### 顧客サービス

**Q7: 顧客が支払いができないと言った場合は？**

A: プロフェッショナルな対応：

1. 落ち着いて共感的に
2. 状況を理解
3. マネージャーを呼ぶ
4. 解決策を議論
5. レストランポリシーに従う
6. すべてを文書化
7. 警察に連絡しない（マネージャーが判断）

**Q8: 顧客が領収書に不満を述べた場合は？**

A: 解決手順：

1. 何が問題か尋ねる
2. 元の注文を確認
3. 間違いがあれば認める
4. 正しい領収書を再発行
5. 謝罪
6. フォローアップして満足度を確認

**Q9: 顧客が会員割引を要求した場合は？**

A: 確認プロセス：

1. 会員番号または電話番号を尋ねる
2. システムで確認
3. 会員ステータスを確認
4. 適用可能な割引を適用
5. 顧客に説明
6. 調整した金額で処理
7. 割引が領収書に表示されることを確認

### レポートと決算

**Q10: 日次レポートの生成方法は？**

A: 手順：

1. **レポート → 日次決算**に移動
2. 日付を選択（通常は今日）
3. 「レポート生成」をクリック
4. 生成を待つ（1-2分）
5. PDFまたはExcelで表示
6. 正確性を確認
7. 印刷して保管
8. マネージャーに提出

**Q11: レポートに間違いを見つけた場合は？**

A: 修正プロセス：

1. 具体的な問題を特定
2. スクリーンショットを撮る
3. マネージャーに報告
4. 修正を待つ
5. 元のレポートを保管
6. 修正されたレポートを取得
7. 両方を提出（比較用）

**Q12: 月次決算を準備する方法は？**

A: 月末手順：

1. 最終日に通常の日次決算を実行
2. **レポート → 月次概要**に移動
3. 月を選択
4. すべての日次レポートが含まれているか確認
5. 月次レポートを生成
6. すべてのデータを確認
7. 異常を強調表示
8. 管理レビューのために準備
