## 🚀 クイックスタート

### MakanMasakチームへようこそ！

配膳スタッフとして、あなたはレストランと顧客の間の重要な架け橋です。主な職責は：

```
┌─────────────────────────────────────────┐
│ 配膳スタッフの核心職責                  │
├─────────────────────────────────────────┤
│                                         │
│  ✅ 新規注文を受信・確認               │
│  ✅ キッチンから料理を受け取り         │
│  ✅ 正しいテーブル/座席に配膳          │
│  ✅ 注文配送状態を更新                 │
│  ✅ 顧客の追加要望に対応               │
│  ✅ 良好なサービス品質を維持           │
│                                         │
└─────────────────────────────────────────┘
```

### 一日の業務フロー概要

```
08:00 システムにログイン → シフトを確認
   ↓
09:00 営業準備 → 食器を確認
   ↓
11:00 営業開始 → 注文を受信
   ↓
11:30 ピーク時間 → 迅速配送
   ↓
14:00 昼休み時間 → 環境整理
   ↓
17:00 夕食準備 → 再度確認
   ↓
21:00 仕上げ作業 → 記録報告
   ↓
21:30 退勤 → 当日業務完了
```

## 🏢 システム概要

### チーム内での配膳スタッフの役割

```
        オーナー
         │
    ┌────┼────┬────┐
    ↓    ↓    ↓    ↓
シェフ 配膳  会計  顧客
    │    │    │    │
    └────┴────┴────┘
         │
   リアルタイム注文システム
```

**役割説明**：

- **シェフ**：料理を準備 → 受取通知
- **あなた（配膳スタッフ）**：料理受取 → 配送 → 状態更新
- **会計**：支払い処理 → 注文完了
- **顧客**：注文 → 待機 → 食事

### 権限範囲

```
┌─────────────────────────────────────────┐
│ 配膳スタッフが実行できる操作            │
├─────────────────────────────────────────┤
│                                         │
│  ✅ 配送待ち注文リストを閲覧           │
│  ✅ 注文詳細内容を閲覧                 │
│  ✅ 注文を「配送中」に更新             │
│  ✅ 注文を「配膳完了」に更新           │
│  ✅ テーブル情報を閲覧                 │
│  ✅ 個人作業記録を閲覧                 │
│  ✅ 個人情報を変更                     │
│                                         │
│  ❌ メニュー価格を変更不可             │
│  ❌ 注文を削除不可                     │
│  ❌ 売上を閲覧不可                     │
│  ❌ 他のスタッフを管理不可             │
│                                         │
└─────────────────────────────────────────┘
```

### ログイン情報例

| 項目             | 説明                                 | 例                                    |
| ---------------- | ------------------------------------ | ------------------------------------- |
| ID               | オーナーが作成したスタッフアカウント | crew001 または your.email@example.com |
| 初期パスワード   | オーナーから提供された一時パスワード | Temp123456                            |

✅ **デフォルトパスワードを変更**

- 安全で覚えやすいパスワードを設定

✅ **個人情報を完成**

- 個人写真をアップロード（オプション）
- 連絡電話番号を記入
- 緊急連絡先を確認

✅ **インターフェースに慣れる**

- 主要機能エリアを閲覧
- 注文閲覧機能をテスト

### 受取確認チェックリスト

キッチンで料理を受け取る際、必ず確認：

| 確認項目      | 確認内容                                           |
| ------------- | -------------------------------------------------- |
| ✅ 注文番号   | システム表示の番号と照合                           |
| ✅ 料理品目   | 一つずつ料理名と数量を確認                         |
| ✅ 料理完全性 | 付け合わせ、ソース、食器が揃っている               |
| ✅ 料理状態   | 温かい料理は十分に熱く、冷たい飲み物は十分に冷たい |
| ✅ 外観品質   | 盛り付けが整っている、こぼれていない               |
| ✅ 特別要望   | 備考を確認（例：辛くしない、ベジタリアン）         |

### 配膳時の注意事項

```
┌─────────────────────────────────────────┐
│ 配膳サービスマナー                      │
├─────────────────────────────────────────┤
│                                         │
│  ✅ DO - するべきこと                  │
│  ─────────────────                      │
│  • 笑顔で挨拶：「こんにちは、お料理です」│
│  • 小声で話し、他の顧客の邪魔をしない  │
│  • 注意深く置く、こぼさないように      │
│  • 特色料理を紹介：「当店の看板メニュー│
│    です」                              │
│  • 積極的に尋ねる：「他に必要なものは  │
│    ありますか？」                      │
│  • 食事を祝福：「お食事をお楽しみください」│
│                                         │
│  ❌ DON'T - 避けるべきこと             │
│  ─────────────────────                  │
│  • テーブルを間違える、番号を確認しない│
│  • 態度が冷たい、アイコンタクトなし    │
│  • 乱暴に皿を置く                      │
│  • 食器や調味料を忘れる                │
│  • 配膳後に状態を更新しない            │
│  • 顧客の質問を無視する                │
│                                         │
└─────────────────────────────────────────┘
```

### 複数注文の同時配送

複数の注文を同時に配送する必要がある場合：

```
効率的配送戦略：

  📍 テーブルエリア別にルートを計画
     │
     ├─ Aエリアテーブル (A1-A5)
     ├─ Bエリアテーブル (B1-B5)
     └─ Cエリアテーブル (C1-C5)

  🎯 バッチ受取と配送
     │
     ├─ 同エリア → 一度に配送
     ├─ 異エリア → 分けて処理
     └─ 温かい料理優先 → 温度維持
```

**実例**：

```
シナリオ：3つの注文が配送待ち

注文 #1234 → A3テーブル → 牛肉麺 (温かい料理)
注文 #1235 → A5テーブル → 炒飯 (温かい料理)
注文 #1236 → B2テーブル → アイスシェイク (冷たい飲み物)

✅ 最適戦略：
  1. 先にA3、A5の温かい料理を受け取る（同エリア）
  2. A3 → A5に配送（順路）
  3. 戻ってB2の冷たい飲み物を受け取る
  4. B2に配送

⏱️ 時間節約：5-10分
```

## ❓ よくある質問

### システム使用関連

**Q1: ログインパスワードを忘れた場合は？**

A: オーナーまたはマネージャーに連絡して、パスワードをリセットしてもらってください。セキュリティ上の理由から、自分でパスワードをリセットすることはできません。

**Q2: 注文通知を受け取れない場合は？**

A: トラブルシューティング手順：

1. 通知設定を確認（設定 → 通知）
2. アプリのバックグラウンド権限を確認
3. アプリを再起動
4. 問題が続く場合はマネージャーに報告

**Q3: 配送中にアプリがクラッシュした場合は？**

A: 対応：

1. アプリを再起動
2. 再ログイン
3. 配送中だった注文を見つける
4. 「配膳完了」状態を更新
5. 技術的問題をマネージャーに報告

### 配膳業務関連

**Q4: テーブルが見つからない場合は？**

A: 手順：

1. フロアマップを確認
2. 他のスタッフに尋ねる
3. 最後の手段として顧客に電話
4. 注文を間違ったテーブルに配送しない

**Q5: 顧客が注文していないと言った場合は？**

A: 確認手順：

1. 落ち着いて丁寧に
2. 注文番号とテーブル番号を再確認
3. 顧客の注文詳細を確認
4. 間違えた場合は謝罪
5. 正しいテーブルを見つける/マネージャーに報告

**Q6: 料理の一部が不足している場合は？**

A: 即座の対応：

1. すぐに顧客に伝える
2. キッチンに残りを依頼
3. 顧客に待つよう丁寧に依頼
4. 残りの料理を優先配送
5. マネージャーに報告

### 顧客サービス関連

**Q7: 顧客が不満を述べた場合は？**

A: 対応手順：

1. 傾聴して共感を示す
2. 誠実に謝罪
3. 解決策を提案
4. すぐにマネージャーに報告
5. フォローアップして顧客が満足しているか確認

**Q8: 顧客から料理について質問された場合は？**

A: 対応：

1. 知っていることを明確に説明
2. 不明な場合は正直に伝える
3. シェフまたはマネージャーに確認すると約束
4. 答えを取得して報告
5. 答えられなかったことを謝罪しない - プロ意識を保つ

**Q9: チップを受け取ってもいいですか？**

A: レストランポリシーを確認：

- 許可されている場合：丁寧に感謝の意を表す
- 許可されていない場合：丁寧に断る
- 不明な場合：マネージャーに確認

### 効率と業績関連

**Q10: 配送速度を上げるには？**

A: 効率アップのコツ：

- 同エリアの注文をまとめる
- フロアレイアウトを記憶
- 準備中に次の注文を計画
- 不必要な往復を避ける
- 他のスタッフと協力

**Q11: 繁忙時の圧力にどう対処しますか？**

A: ストレス管理：

- 落ち着いて集中
- 一度に一つの注文に集中
- 深呼吸
- チームとコミュニケーション
- 完璧より進歩を重視

**Q12: 業績を向上させるには？**

A: 改善戦略：

- 毎日の記録を確認
- ベテランスタッフから学ぶ
- フィードバックを求める
- 効率を重視
- ポジティブな態度を維持
