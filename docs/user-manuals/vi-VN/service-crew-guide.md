## 🚀 Bắt Đầu Nhanh

### Chào Mừng Bạn Đến Với Đội Ngũ MakanMasak!

Là nhân viên phục vụ, bạn là cầu nối quan trọng giữa nhà hàng và khách hàng. Trách nhiệm chính của bạn là:

```
┌─────────────────────────────────────────┐
│ Trách Nhiệm Cốt Lõi                     │
├─────────────────────────────────────────┤
│                                         │
│  ✅ Nhận và xem đơn hàng mới           │
│  ✅ Lấy món từ bếp                     │
│  ✅ Giao món đến đúng bàn/ghế          │
│  ✅ Cập nhật trạng thái giao món       │
│  ✅ Đáp ứng yêu cầu của khách          │
│  ✅ Duy trì chất lượng phục vụ         │
│                                         │
└─────────────────────────────────────────┘
```

### Quy Trình Làm Việc Hàng Ngày

```
08:00 Đăng nhập → Kiểm tra lịch
   ↓
09:00 Chuẩn bị → Kiểm tra đồ dùng
   ↓
11:00 Bắt đầu phục vụ → Nhận đơn
   ↓
11:30 Giờ cao điểm → Giao món nhanh
   ↓
14:00 Giờ nghỉ → Dọn dẹp môi trường
   ↓
17:00 Chuẩn bị buổi tối → Kiểm tra lại
   ↓
21:00 Kết thúc → Ghi chép báo cáo
   ↓
21:30 Đăng xuất → Hoàn thành công việc
```

## 🏢 Tổng Quan Hệ Thống

### Vai Trò Của Bạn Trong Đội Ngũ

```
        Chủ Nhà Hàng
              │
    ┌─────────┼─────────┬────────┐
    ↓         ↓         ↓        ↓
  Đầu Bếp  Phục Vụ  Thu Ngân  Khách
    │         │         │        │
    └─────────┴─────────┴────────┘
              │
     Hệ Thống Đơn Hàng
```

**Giải Thích Vai Trò**:

- **Đầu Bếp**: Chuẩn bị món → Thông báo lấy món
- **Bạn (Phục Vụ)**: Lấy món → Giao món → Cập nhật trạng thái
- **Thu Ngân**: Xử lý thanh toán → Hoàn tất đơn
- **Khách Hàng**: Đặt món → Chờ → Dùng bữa

### Danh Sách Việc Cần Làm Lần Đầu

✅ **Đổi Mật Khẩu Mặc Định**

- Đặt mật khẩu an toàn và dễ nhớ
- Không chia sẻ với người khác

✅ **Hoàn Thành Hồ Sơ**

- Tải ảnh đại diện (tùy chọn)
- Điền số điện thoại liên lạc
- Xác nhận người liên hệ khẩn cấp

✅ **Làm Quen Giao Diện**

- Duyệt các khu vực chức năng
- Thử xem đơn hàng
- Hiểu cách cập nhật trạng thái

### Giao Nhiều Đơn Cùng Lúc

Khi giao nhiều đơn cùng lúc:

```
Chiến Lược Giao Món Hiệu Quả:

  📍 Lập kế hoạch theo khu vực bàn
     │
     ├─ Khu A (A1-A5)
     ├─ Khu B (B1-B5)
     └─ Khu C (C1-C5)

  🎯 Lấy và giao theo lô
     │
     ├─ Cùng khu → Giao cùng lúc
     ├─ Khác khu → Giao riêng
     └─ Món nóng trước → Giữ nhiệt độ
```

**Ví Dụ**:

```
Tình huống: 3 đơn chờ

Đơn #1234 → Bàn A3 → Phở Bò (nóng)
Đơn #1235 → Bàn A5 → Cơm Chiên (nóng)
Đơn #1236 → Bàn B2 → Sinh Tố (lạnh)

✅ Chiến Lược Tốt Nhất:
  1. Lấy món nóng A3, A5 trước (cùng khu)
  2. Giao A3 → A5 (đường đi thuận)
  3. Quay lại lấy đồ lạnh B2
  4. Giao B2

⏱️ Tiết Kiệm: 5-10 phút
```
