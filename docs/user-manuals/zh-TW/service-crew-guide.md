## 🚀 快速入門

### 歡迎加入 MakanMakan 團隊！

作為服務員，您是餐廳與顧客之間的重要橋樑。您的主要職責是：

```
┌─────────────────────────────────────────┐
│ 服務員核心職責                          │
├─────────────────────────────────────────┤
│                                         │
│  ✅ 接收並查看新訂單                   │
│  ✅ 從廚房取餐                         │
│  ✅ 送餐至正確桌位/座位                │
│  ✅ 更新訂單配送狀態                   │
│  ✅ 回應顧客額外需求                   │
│  ✅ 維護良好服務品質                   │
│                                         │
└─────────────────────────────────────────┘
```

### 一天工作流程概覽

```
08:00 登入系統 → 查看排班
   ↓
09:00 準備營業 → 檢查餐具
   ↓
11:00 開始營業 → 接收訂單
   ↓
11:30 高峰時段 → 快速配送
   ↓
14:00 午休時段 → 整理環境
   ↓
17:00 晚餐準備 → 再次檢查
   ↓
21:00 收尾工作 → 記錄回報
   ↓
21:30 下班簽退 → 完成當日任務
```

## 🏢 系統概覽

### 服務員在團隊中的角色

```
        店主
         │
    ┌────┼────┬────┐
    ↓    ↓    ↓    ↓
  廚師 服務員 收銀 顧客
    │    │    │    │
    └────┴────┴────┘
         │
   即時訂單系統
```

**角色說明**：

- **廚師**：準備餐點 → 通知取餐
- **您（服務員）**：取餐 → 配送 → 更新狀態
- **收銀**：處理付款 → 完成訂單
- **顧客**：點餐 → 等待 → 用餐

## 🔐 登入與基本操作

### 首次登入流程

```
┌──────────────────────────────────────────┐
│ 登入步驟                                 │
├──────────────────────────────────────────┤
│                                          │
│  1️⃣ 開啟 MakanMakan 服務員 App          │
│      ↓                                   │
│  2️⃣ 輸入店主提供的帳號密碼              │
│      ↓                                   │
│  3️⃣ 首次登入須修改密碼                  │
│      ↓                                   │
│  4️⃣ 完成個人資料設定                    │
│      ↓                                   │
│  5️⃣ 進入服務員工作台                    │
│                                          │
└──────────────────────────────────────────┘
```

### 登入資訊範例

| 項目       | 說明                          | 範例                              |
| ---------- | ----------------------------- | --------------------------------- |
| 帳號       | 由店主建立的員工帳號          | crew001 或 your.email@example.com |
| 初始密碼   | 店主提供的臨時密碼            | Temp123456                        |
| 新密碼要求 | 至少 8 個字元，包含英文和數字 | MyPass2025!                       |

### 首次登入必做事項

✅ **修改預設密碼**

- 設定安全且容易記住的密碼
- 不要與他人共享密碼

✅ **完成個人資料**

- 上傳個人照片（選填）
- 填寫聯絡電話
- 確認緊急聯絡人

✅ **熟悉介面**

- 瀏覽主要功能區
- 測試訂單查看功能
- 了解狀態更新方式

### 取餐核對清單

在廚房取餐時，請務必確認：

| 檢查項目    | 確認內容                     |
| ----------- | ---------------------------- |
| ✅ 訂單編號 | 核對系統顯示的編號           |
| ✅ 餐點品項 | 逐項確認菜名與數量           |
| ✅ 餐點完整 | 配菜、醬料、餐具齊全         |
| ✅ 餐點狀態 | 熱食夠熱、冷飲夠冷           |
| ✅ 外觀品質 | 擺盤整齊、無灑漏             |
| ✅ 特殊需求 | 查看備註（如：不要辣、素食） |

### 送餐注意事項

```
┌─────────────────────────────────────────┐
│ 送餐服務禮儀                            │
├─────────────────────────────────────────┤
│                                         │
│  ✅ DO - 應該這樣做                    │
│  ─────────────────                      │
│  • 微笑問候：「您好，這是您的餐點」    │
│  • 輕聲細語，不打擾其他顧客            │
│  • 小心放置，避免打翻                  │
│  • 介紹特色菜：「這是本店招牌」        │
│  • 主動詢問：「還需要其他服務嗎？」    │
│  • 祝福用餐：「祝您用餐愉快」          │
│                                         │
│  ❌ DON'T - 避免這樣做                 │
│  ─────────────────────                  │
│  • 送錯桌位，未確認桌號                │
│  • 態度冷漠，無眼神接觸                │
│  • 粗魯放置餐盤                        │
│  • 忘記餐具或調味料                    │
│  • 送餐後未更新狀態                    │
│  • 忽略顧客提出的問題                  │
│                                         │
└─────────────────────────────────────────┘
```

### 多訂單同時配送

當需要同時配送多筆訂單時：

```
高效配送策略：

  📍 依桌位區域規劃路線
     │
     ├─ A 區桌位 (A1-A5)
     ├─ B 區桌位 (B1-B5)
     └─ C 區桌位 (C1-C5)

  🎯 批次取餐與配送
     │
     ├─ 同一區域 → 一次配送
     ├─ 不同區域 → 分批處理
     └─ 熱食優先 → 保持溫度
```

**實例**：

```
情境：3 筆訂單待送

訂單 #1234 → A3 桌 → 牛肉麵 (熱食)
訂單 #1235 → A5 桌 → 炒飯 (熱食)
訂單 #1236 → B2 桌 → 冰沙 (冷飲)

✅ 最佳策略：
  1. 先取 A3、A5 的熱食（同區域）
  2. 配送 A3 → A5（順路）
  3. 返回取 B2 的冷飲
  4. 配送 B2

⏱️ 節省時間：5-10 分鐘
```

### Q2: 訂單顯示「可取餐」但廚房說還沒好？

```
A: 可能是狀態更新延遲

  ✅ 正確做法：
     • 向廚師確認實際情況
     • 相信廚師的判斷
     • 等待餐點真正完成
     • 不要急促催促廚房
     • 如頻繁發生，回報主管
```

---

### Q3: 顧客說訂單裡有錯誤，該怎麼處理？

```
A: 訂單錯誤處理流程

  步驟 1: 查看系統訂單明細
         └─ 確認是顧客點錯還是系統錯誤

  步驟 2: 如果是顧客點錯
         └─ 禮貌說明「這是您點的餐點」
         └─ 詢問是否要加點其他項目
         └─ 引導顧客向收銀諮詢

  步驟 3: 如果是廚房做錯
         └─ 立即道歉
         └─ 通知廚房重做
         └─ 向顧客說明等待時間

  步驟 4: 記錄事件
         └─ 在系統留下備註
         └─ 向主管簡短報告
```

### Q4: 高峰時段訂單太多，送不過來怎麼辦？

```
     ├─ 第一優先: 等待超過 10 分鐘的訂單
     ├─ 第二優先: 熱食（避免變冷）
     ├─ 第三優先: 同區域多筆訂單（批次配送）
     └─ 第四優先: 冷飲、甜點

  🤝 尋求協助
     │
     ├─ 請求其他服務員支援
     ├─ 向主管說明需要人力
     └─ 廚房優先完成老訂單

  💡 提升效率
     │
     ├─ 使用托盤一次送多份
     ├─ 規劃最短配送路線
     └─ 減少來回廚房次數
```
