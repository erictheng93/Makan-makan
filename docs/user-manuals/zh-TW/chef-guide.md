## 🚀 快速入門

### 廚師的核心職責

```
┌─────────────────────────────────────────────┐
│ 廚師工作流程                                │
├─────────────────────────────────────────────┤
│                                             │
│  1️⃣ 接收新訂單                             │
│      ↓                                      │
│  2️⃣ 確認訂單內容                           │
│      ↓                                      │
│  3️⃣ 更新為「準備中」                       │
│      ↓                                      │
│  4️⃣ 開始烹飪                               │
│      ↓                                      │
│  5️⃣ 完成後更新為「已完成」                 │
│      ↓                                      │
│  6️⃣ 通知送菜員取餐                         │
│                                             │
└─────────────────────────────────────────────┘
```

### 首次使用檢查清單

✅ **第一步：確認帳號與設備**

- 確認已取得廚師帳號
- 測試登入廚房顯示系統
- 確認顯示螢幕可正常顯示

✅ **第二步：熟悉介面**

- 了解訂單卡片佈局
- 練習狀態更新操作
- 測試音效通知

✅ **第三步：了解流程**

- 新訂單通知方式
- 狀態更新步驟
- 完成訂單流程

✅ **第四步：準備工作**

- 確認廚房設備就緒
- 檢查食材備料
- 開始接收訂單

```
┌─────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────┤
│                                                         │
│  顧客下單 ───→ 訂單系統 ───→ 廚房顯示 ───→ 送菜確認   │
│                     ↓            ↓            ↓         │

│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 廚房角色協作模式

```
        訂單來源
           │
    ┌──────┴──────┐
    ↓             ↓
  桌台訂單     店家訂單
    │             │
    └──────┬──────┘
           ↓
    【廚房顯示系統】
     (您的工作站)
           │
    ┌──────┴──────┐
    ↓             ↓
  送菜員       顧客端
  確認送達     即時追蹤
```

**說明**：

- **顧客**：透過 QR Code 下單
- **廚房系統**：即時接收並顯示訂單
- **廚師（您）**：處理訂單並更新狀態
- **送菜員**：取餐並送達顧客
- **店主**：監控整體營運狀況

**步驟 1：開啟廚房顯示系統**

前往：廚房平板或顯示器上的系統網址

```
網址範例:
https://kitchen.makanmakan.com
或
https://your-restaurant.makanmakan.com/kitchen
```

```
┌─────────────────────────────┐
```

### 狀態更新操作

**更新為「準備中」**

當您準備開始製作時：

```
┌─────────────────────────┐
│ #025 - 7號桌            │
├─────────────────────────┤
│ • 海鮮炒飯 x1          │
│ • 酸辣湯 x2            │
│                         │
│ [✋ 開始製作]           │  ← 點擊這個按鈕
└─────────────────────────┘

點擊後 ↓

┌─────────────────────────┐
│ #025 - 7號桌  ⏱️ 3:25   │
├─────────────────────────┤
│ • 海鮮炒飯 x1          │
│ • 酸辣湯 x2            │
│                         │
│ [✓ 完成製作]           │  ← 狀態已更新
└─────────────────────────┘
```

**更新為「已完成」**

當菜品烹飪完成時：

```
準備中 → 已完成

操作步驟:
1. 確認所有品項已完成
2. 檢查品質與外觀
3. 點擊「完成製作」按鈕
4. 卡片移至「已完成」欄位
5. 系統自動通知送菜員
```
