## 系統簡介 System Overview

### 關於 AI 智能分析系統 About the AI Analytics System

AI 智能分析系統是 MakanMakan 餐廳管理系統的高級功能模組，整合了多個領先的大型語言模型（LLM），為餐廳經營者提供基於數據的智能商業洞察和決策建議。

The AI Analytics System is an advanced feature module of the MakanMakan Restaurant Management System, integrating multiple leading Large Language Models (LLMs) to provide restaurant operators with data-driven intelligent business insights and decision recommendations.

### 角色說明 Role Descriptions

**管理員 Admin (role=0)**：

- 完整系統管理權限
- 可配置所有餐廳的 AI 設定
- 可查看跨餐廳使用統計
- 可管理 API 使用額度

**店主 Owner (role=1)**：

- 管理自己餐廳的 AI 設定
- 查看自己餐廳的分析報告
- 無法訪問其他餐廳數據
- 建議的主要使用角色

**其他角色**：

- 無法訪問 AI Analytics 功能
- 側邊欄不顯示「AI 洞察」選項
- 直接輸入 URL 會被拒絕訪問

#### 步驟 1：取得 API Key Get API Key

**Anthropic Claude API Key**：

```
1️⃣ 前往 Anthropic 官網
   https://console.anthropic.com/

2️⃣ 註冊帳號
   • 使用 Email 註冊
   • 驗證 Email 地址
   • 完成基本資料

3️⃣ 前往 API Keys 頁面
   左側選單 → Settings → API Keys

4️⃣ 創建新的 API Key
   • 點擊 "Create Key" 按鈕
   • 輸入 Key 名稱（例如：MakanMakan）
   • 選擇權限（建議 Full Access）

5️⃣ 複製 API Key
   • 格式：sk-ant-api03-xxx...
   • ⚠️ 只會顯示一次，請立即保存
   • 建議存在密碼管理器中

6️⃣ 儲值額度（如需要）
   Settings → Billing → Add credits
   建議初次儲值 $10-20 USD
```

**OpenAI API Key**：

```
1️⃣ 前往 OpenAI Platform
   https://platform.openai.com/

2️⃣ 登入帳號
   使用 Google/Microsoft 或 Email 登入

3️⃣ 前往 API Keys
   左側選單 → API Keys

4️⃣ 創建新的 Secret Key
   • 點擊 "Create new secret key"
   • 輸入名稱（例如：MakanMakan）
   • 選擇專案（如有）

5️⃣ 複製 API Key
   • 格式：sk-proj-xxx... 或 sk-xxx...
   • ⚠️ 只會顯示一次

6️⃣ 設定使用限制（建議）
   Settings → Limits
   設定每月預算上限
```

```

   https://makersuite.google.com/

2️⃣ 登入 Google 帳號
```

## 成本設定 Cost Configuration

### 為什麼需要設定成本 Why Cost Configuration is Needed

```
利潤分析功能依賴準確的成本數據：

沒有成本數據 → 無法計算利潤 → 「利潤最大」Tab 顯示「資料不足」

有成本數據 → 可計算利潤 → 完整的利潤分析和排名
```

### 成本數據結構 Cost Data Structure

```
每個菜品的成本包含三部分：

┌─────────────────────────────────────────┐
│ 菜品成本組成                            │
├─────────────────────────────────────────┤
│                                         │
│ 1️⃣ 食材成本 Ingredient Cost            │
│    • 主要食材採購成本                   │
│    • 調味料成本                         │
│    • 包裝成本                           │
│    範例：牛肉麵 = $50                   │
│                                         │
│ 2️⃣ 人工成本 Labor Cost                 │
│    • 備料時間成本                       │
│    • 烹飪時間成本                       │
│    範例：牛肉麵 = $10                   │
│                                         │
│ 3️⃣ 管理費用 Overhead Cost              │
│    • 水電瓦斯費                         │
│    • 設備折舊                           │
│    • 場地租金分攤                       │
│    範例：牛肉麵 = $5                    │
│                                         │
│ 總成本 Total Cost（自動計算）           │
│ = 食材成本 + 人工成本 + 管理費用        │
│ = $50 + $10 + $5 = $65                 │
│                                         │
│ 利潤率 Profit Margin（自動計算）        │
│ = (售價 - 總成本) ÷ 售價                │
│ = ($120 - $65) ÷ $120 = 45.8%          │
│                                         │
└─────────────────────────────────────────┘
```

### 設定方法 Configuration Methods

**方法 1：透過管理介面（推薦）**

```
步驟 1: 前往菜單管理
  管理後台 → 菜單管理

步驟 2: 選擇菜品
  找到要設定成本的菜品
```

**問題 1: 找不到 AI 洞察選項**

```
症狀：
  • 側邊欄沒有「✨ AI 洞察」選項
  • 直接輸入 URL 返回 403 錯誤

原因分析：
  • 帳號角色不是 Admin 或 Owner
  • 前端部署未完成
  • 瀏覽器快取過舊

解決步驟：

步驟 1: 確認帳號角色
  管理後台 → 個人資料 → 查看角色
  確保角色為 Admin (0) 或 Owner (1)

步驟 2: 清除瀏覽器快取
  Ctrl+Shift+Delete → 清除快取和 Cookie
  重新整理頁面

步驟 3: 檢查前端部署
  聯繫技術支援確認 AI Analytics 前端已部署

步驟 4: 檢查權限設定
  如果問題持續，請聯繫管理員檢查權限配置
```

```
錯誤訊息：「API Key 無效」

可能原因與解決方案：

原因 1: API Key 複製不完整
  ✅ 重新從 Provider 官網完整複製
  ✅ 確保沒有多餘空格

  ✅ 前往 Provider 官網檢查 Key 狀態

  ✅ 確認 Key 有「Generate Text」權限
  ✅ 重新生成具完整權限的 Key

原因 4: 帳戶額度不足
  ✅ 檢查 Provider 帳戶餘額
  ✅ 充值後重試
```

### Q5: 如果 AI 建議與我的經驗相悖怎麼辦？

```
A: 這是正常現象。結合 AI 建議與您的經驗才是最佳做法。

處理步驟：

步驟 1: 理解 AI 的邏輯
   • AI 基於什麼數據？
   • AI 考慮了哪些因素？
   • AI 的信心指數是多少？

步驟 2: 分析差異原因
   可能原因：
     • AI 缺少某些背景資訊
     • 數據未反映最新變化
     • 您的經驗來自特殊案例
     • 市場環境已改變

步驟 3: 評估風險與收益
   ┌─────────────────────────────────┐
   │ 決策矩陣                        │
   ├─────────────────────────────────┤
   │                                 │
   │ 如果 AI 對，您錯：              │
   │   • 錯失機會                    │
   │   • 成本：中等                  │
   │                                 │
   │ 如果 AI 錯，您對：              │
   │   • 避免損失                    │
   │   • 成本：無                    │
   │                                 │
   │ 如果嘗試 AI 建議：              │
   │   • 可能發現新機會              │
   │   • 成本：小規模測試成本        │
   │                                 │
   └─────────────────────────────────┘

步驟 4: 小規模測試
   • 不要立即全面採納
   • 先小範圍測試
   • 收集數據驗證
   • 根據結果決定

步驟 5: 持續學習
   • 記錄 AI 建議
   • 記錄您的決策
   • 記錄實際結果
   • 總結經驗教訓

範例：

情況: AI 建議調漲「炸雞排」價格 15%
您的經驗: 客戶對價格敏感

處理方式:
  1. 小幅測試（先調漲 8%）
  2. 觀察 2 週訂單變化
  3. 如果訂單穩定，再調至 15%
  4. 如果訂單下降，恢復原價
  5. 記錄結果，回饋給 AI

結論：
  AI 是輔助工具，不是替代您的經驗
  最佳決策 = AI 數據分析 + 您的實務經驗
```

### Q6: 系統如何保護我的 API Key 安全？

```

   • API Key 在資料庫中加密儲存
   • 使用 AES-256 加密演算法
   • 加密金鑰安全管理
   • 無人可直接讀取

2️⃣ HTTPS 傳輸加密
   • 所有 API Key 傳輸使用 HTTPS
   • TLS 1.3 協議
   • 防止中間人攻擊

3️⃣ 權限控制
   • 只有 Admin 和 Owner 可配置
   • 角色權限嚴格驗證
   • 每次操作都需身份驗證

4️⃣ 不明文顯示
   • 系統不會明文顯示已保存的 Key
   • 只能重新輸入覆蓋
   • 防止螢幕截圖洩露

5️⃣ 審計日誌
   • 記錄所有 API Key 操作
   • 記錄操作人、時間、動作
   • 可追蹤異常操作

6️⃣ 最佳實踐建議
   • 定期更換 API Key（每季度）
   • 在 Provider 設定使用限制
   • 監控 API 使用異常
   • 離職員工立即更換 Key

如何檢查安全性：
  ✅ 資料庫中 API Key 欄位是加密的
  ✅ 網頁顯示為 ••••••••
  ✅ 只有您和系統管理員可存取
  ✅ 所有操作都有審計記錄
```

### A. 術語表 Glossary

```
AI Analytics: AI 智能分析系統

LLM (Large Language Model): 大型語言模型

Provider: AI 服務提供商（如 Anthropic, OpenAI）

API Key: 應用程式介面金鑰，用於身份驗證

Token: 文字處理單位（約 0.75 個英文字或 0.5 個中文字）

Confidence Score: 信心指數，AI 對洞察可靠性的評估

Impact Level: 影響程度，洞察對業務的影響大小

Traffic Driver: 引流產品，吸引客戶進店的產品

Bestseller: 熱銷產品，銷量最高的產品

Profit Leader: 利潤最大產品，最賺錢的產品

Profit Margin: 利潤率，(售價-成本)/售價

TTL (Time To Live): 快取有效期

Cache: 快取，暫存的數據

Webhook: 網頁鉤子，自動通知機制
```
