## 🎉 Maligayang Pagdating sa MakanMakan

Ang MakanMakan ay isang modernong smart ordering platform na nagbibigay-daan sa iyo na tingnan ang menu, mag-order, at subaybayan ang status ng order nang real-time gamit ang iyong smartphone. Walang kailangang i-download na app - i-scan lang ang QR code para magsimula!

### ✨ Pangunahing Features

- 📱 **Walang App Download** - Gamitin direkta mula sa mobile browser
- 🎯 **Simple at Mabilis** - I-scan ang QR code para mag-order
- 📊 **Real-time Tracking** - Tingnan ang status ng order anumang oras
- 💾 **Offline Support** - Gumagana kahit hindi stable ang internet
- 👤 **Member System** - Tingnan ang order history pagkatapos mag-register
- 🌐 **Multi-language** - Traditional Chinese, English, Vietnamese, Indonesian, Filipino

## 🍽️ Paraan ng Pag-order

Ang MakanMakan ay nag-aalok ng dalawang paraan ng pag-order, depende sa setup ng restaurant:

### Paraan 1: I-scan ang QR Code ng Mesa

**Para sa**: Dine-in restaurant na may fixed seating

#### 📍 Paano Gamitin

1. **Hanapin ang QR Code ng Mesa**
   - Karaniwang nakalagay sa mesa, table stand, o gamit
   - Bawat mesa ay may sariling unique na QR code

2. **I-scan ang QR Code**

   ```
   Opsyon 1: Gumamit ng phone camera
   └─ Buksan ang camera at itutok sa QR code
   └─ I-tap ang notification link

   Opsyon 2: Gumamit ng LINE/WeChat scanner
   └─ Buksan ang scan function
   └─ Itutok sa QR code
   ```

3. **Magsimulang Mag-order**
   - Awtomatikong bubukas ang menu page pagkatapos mag-scan
   - Ang iyong order ay konektado sa mesa na ito
   - Walang kailangang registration

#### 🎯 Features

- ✅ Direktang mag-order, walang registration
- ✅ Awtomatikong napapunta sa kusina ang order
- ✅ Makikita ng staff ang iyong table number
- ✅ Pwedeng magdagdag ng order (i-scan ulit)

---

### Paraan 2: I-scan ang QR Code ng Tindahan

**Para sa**: Takeaway counter, stall, pop-up store, food truck

#### 📍 Paano Gamitin

1. **I-scan ang QR Code ng Tindahan**
   - Karaniwang nasa counter o harap ng tindahan
   - Isang QR code lang para sa buong tindahan

2. **Kailangan ng Phone Verification (Una)**

   **Hakbang 1: Ilagay ang Phone Number**

   ```
   ┌──────────────────────────┐
   │  Ilagay ang phone number │
   │  ┌────────────────────┐  │
   │  │ +63 912345678      │  │
   │  └────────────────────┘  │
   │                          │
   │  [Kumpirmahin]           │
   └──────────────────────────┘
   ```

   - Ilagay ang phone number kasama ang country code
   - Halimbawa: Pilipinas +63, Malaysia +60

   **Hakbang 2: Ilagay ang Verification Code (Opsyonal)**
   - May mga restaurant na nangangailangan ng phone verification
   - Makakatanggap ka ng 6-digit code sa SMS
   - Ilagay ang code para kumpletuhin ang verification

3. **Magsimulang Mag-order**
   - Tingnan ang menu pagkatapos ng verification
   - Idagdag sa cart at isumite ang order

4. **Kunin ang Order**
   - Makikita sa order ang huling 4 digits ng phone mo
   - Tatawagan ka ng staff gamit ang number mo
   - Halimbawa: "Number 5678, ready na po ang order!"

#### 🎯 Features

- ✅ Perpekto para sa takeaway
- ✅ Phone number bilang pickup reference
- ✅ Tingnan ang order status
- ✅ Suportado ang pre-order

## ❓ Mga Madalas na Tanong (FAQ)

### 🤔 Pangkalahatang Paggamit

**Q1: Kailangan ba ng download ng app?**
A: Hindi! I-scan lang ang QR code gamit ang mobile browser.

**Q2: Kailangan ba mag-register para mag-order?**
A: Hindi naman. Pwedeng mag-order sa table nang walang registration. Pero mag-register para makita ang order history.

**Q3: Hindi nakatanggap ng verification code?**
A: Tingnan:

- Tama ba ang phone number
- Hindi ba na-block bilang spam ang SMS
- Stable ba ang internet connection
- Makipag-ugnayan sa staff para sa tulong

**Q4: Pwede bang mag-order para sa dalawang mesa nang sabay?**
A: Hindi inirerekomenda. Bawat mesa ay may sariling QR code, i-scan ng hiwalay.

**Q5: Pwede bang kanselahin pagkatapos isumite?**
A: Hindi pwede sa system, makipag-ugnayan agad sa staff.

---

### 🛒 Shopping Cart

**Q6: May time limit ba ang cart?**
A: Nakaimbak ng 24 oras, maaaring mabura pagkatapos ng timeout.

**Q7: Bakit hindi pwedeng idagdag ang ilang menu items?**
A: Maaaring dahil sa:

- Ubos na pansamantala ang item
- Hindi kasama sa serving hours
- System maintenance

**Q8: Pwede bang mag-order mula sa maraming restaurant nang sabay?**
A: Hindi. Isang cart lang para sa isang restaurant.

---

### 💰 Bayad

**Q9: Paano magbayad?**
A: Sa kasalukuyan, bayad sa lugar, magbayad sa counter pagkatapos kumain.

**Q10: Pwede bang gumamit ng credit card o mobile payment?**
A: Depende sa patakaran ng restaurant, tanungin ang staff para makumpirma.

---

### 📱 Teknikal

**Q11: Bakit mabagal ang pag-load?**
A: Maaaring dahil sa:

- Mahinang internet signal
- Kulang ang memory ng phone
- Subukang i-refresh ang page

**Q12: Pwede bang gamitin offline?**
A: Pwedeng tingnan ang na-load na menu, pero kailangan ng internet para mag-submit ng order.

**Q13: Aling browsers ang sinusuportahan?**
A: Inirerekomenda:

- Safari (iOS)
- Chrome (Android)
- Iba pang modern browsers

**Q14: Pwede bang gamitin sa computer?**
A: Pwede, pero optimized para sa mobile. Inirerekomenda ang phone para sa best experience.

---

### 🔐 Account

**Q15: Nakalimutan ang password?**
A: I-click ang "Nakalimutan ang Password" sa login page, i-reset gamit ang registered email.

**Q16: Pwede bang palitan ang phone number?**
A: Sa kasalukuyan hindi sinusuportahan, makipag-ugnayan sa customer service.

**Q17: Pwede bang tanggalin ang account?**
A: Makipag-ugnayan sa customer service para hilingin ang pag-delete ng account.

### I-clear ang Browser Cache

Kung may kakaibang pagpapakita ang page, subukang i-clear ang cache:

**iOS Safari:**

1. Pumunta sa "Settings" → "Safari"
2. I-tap ang "Clear History and Website Data"
3. Kumpirmahin ang pag-clear

**Android Chrome:**

1. I-tap ang menu sa taas na kanan (tatlong tuldok)
2. Pumunta sa "Settings" → "Privacy"
3. I-tap ang "Clear browsing data"
4. Piliin ang "Cached images and files"
5. I-tap ang "Clear data"

## 📞 Makipag-ugnayan sa Amin

Kung hindi nakatulong ang gabay na ito, makipag-ugnayan sa:

### 🏪 Restaurant Staff

- **Pinakamabilis**: Magtanong sa staff sa lugar
- Angkop para sa: Mga problema sa pag-order, order issues, bayad

### 💬 Online Support

- **Email**: support@makanmakan.com
- **Response time**: 1-2 araw na trabaho
- Angkop para sa: Account issues, technical problems, feedback

### 📱 Social Media

- **Facebook**: MakanMakan Taiwan
- **Instagram**: @makanmakan_tw
- **LINE**: @makanmakan

### 🐛 Mag-report ng Issues

Nakakita ng bug o may mga mungkahi? Malugod naming tinatanggap ang iyong feedback!

**Kapag nag-report, magbigay ng:**

- Oras ng nangyari ang problema
- Phone model at browser na ginamit
- Detalyadong paglalarawan ng problema
- Screenshots (kung maaari)
