# AI Analytics 快速開始指南

## 🚀 如何進入 AI 統計與分析介面

### 方法 1：通過側邊欄導航（推薦）

1. **啟動 Admin Dashboard**

   ```bash
   cd apps/admin-dashboard
   pnpm run dev
   ```

2. **登入系統**
   - 使用管理員帳號（role=0）或店主帳號（role=1）
   - URL: `http://localhost:5173/login`

3. **點擊側邊欄的「✨ AI 洞察」**

   ```
   📋 儀表板
   🛒 訂單管理
   📖 菜單管理
   🪑 桌台管理
   👥 員工管理
   🎫 優惠券管理
   📊 數據分析
   ✨ AI 洞察  ← 點擊這裡！
   💳 POS系統
   ...
   ```

4. **使用頁面內導航切換功能**

   在任何 AI Analytics 頁面頂部，都有快速導航標籤：

   ```
   [AI 洞察] [產品分析] [AI 配置]
   ```

   - **AI 洞察**：查看 AI 生成的業務分析報告
   - **產品分析**：查看引流/熱銷/利潤產品排名
   - **AI 配置**：配置 AI Provider 和 API Key

---

### 方法 2：直接訪問 URL

如果側邊欄沒有顯示，可以直接在瀏覽器輸入：

```
http://localhost:5173/dashboard/ai-analytics/insights   # AI 洞察
http://localhost:5173/dashboard/ai-analytics/products   # 產品分析
http://localhost:5173/dashboard/ai-analytics/config     # AI 配置
```

## 📱 完整使用流程

### 第一次使用（配置 AI）

```
步驟 1: 點擊側邊欄「✨ AI 洞察」
   ↓
步驟 2: 點擊頁面內「AI 配置」標籤
   ↓
步驟 3: 選擇 AI Provider（例如：Anthropic Claude）
   ↓
步驟 4: 輸入 API Key
   ↓
步驟 5: 點擊「測試連接」
   ↓
步驟 6: 測試成功後，點擊「保存配置」
   ↓
完成！現在可以使用 AI 分析功能了
```

### 查看 AI 洞察

```
步驟 1: 點擊「AI 洞察」標籤
   ↓
步驟 2: 選擇時間範圍（7天/14天/30天/90天）
   ↓
步驟 3: 等待 AI 生成報告（首次需要幾秒鐘）
   ↓
步驟 4: 查看關鍵指標、執行摘要、智能洞察
   ↓
步驟 5: 根據 AI 建議採取行動
```

### 分析產品表現

```
步驟 1: 點擊「產品分析」標籤
   ↓
步驟 2: 選擇分析維度 Tab
   - 引流產品：吸引客戶的產品
   - 熱銷產品：銷量最高的產品
   - 利潤最大：最賺錢的產品
   ↓
步驟 3: 查看 Top 10 產品排名
   ↓
步驟 4: 閱讀底部智能建議
   ↓
步驟 5: 優化菜單和促銷策略
```

## 🔐 權限要求

只有以下角色可以訪問 AI Analytics：

- ✅ **Admin (role=0)** - 系統管理員
- ✅ **Owner (role=1)** - 店主

其他角色（廚師、服務員、收銀員）無法訪問。

如果看不到「✨ AI 洞察」菜單項，請檢查：

1. 是否使用正確的帳號登入
2. 帳號角色是否為 Admin 或 Owner

## 💡 常見問題

### Q1: 找不到「AI 洞察」菜單項？

**A**: 檢查：

1. 是否使用 Admin 或 Owner 帳號登入
2. 前端是否已編譯（`pnpm run dev` 或 `pnpm run build`）
3. 瀏覽器是否需要清除緩存（Ctrl+Shift+R 強制刷新）

### Q2: 點擊「AI 洞察」後顯示 404？

**A**: 檢查路由是否正確配置：

- 檔案：`apps/admin-dashboard/src/router/index.ts`
- 應包含三個路由：`ai-analytics/config`, `ai-analytics/insights`, `ai-analytics/products`

### Q3: 頁面導航標籤沒有高亮當前頁面？

**A**: 這是 Vue Router 的動態 class 問題，不影響功能。
當前頁面的標籤會顯示為藍色背景（`bg-indigo-600`），其他為灰色。

### Q4: 側邊欄收起時看不到「AI 洞察」文字？

**A**: 這是正常設計。側邊欄收起時只顯示圖標（✨ Sparkles 圖標）。
將滑鼠懸停在圖標上或展開側邊欄即可看到完整文字。
