## 🔧 修復詳情

### 【BUG-FIX-1】正則表達式不必要的轉義字符

**位置**: `apps/api/src/features/authentication/schemas/validation.ts:57`

**問題描述**:
在正則表達式字符類 `[]` 中使用了不必要的轉義字符 `\+`, `\(`, `\)`，違反了 ESLint 的 `no-useless-escape` 規則。

**錯誤信息**:
```
57:19  error  Unnecessary escape character: \+  no-useless-escape
57:21  error  Unnecessary escape character: \(  no-useless-escape
57:23  error  Unnecessary escape character: \)  no-useless-escape
```

**修復前**:
```typescript
const phoneSchema = z.string()
  .regex(/^[\d\s\-\+\(\)]+$/, 'Invalid phone number format')
```

**修復後**:
```typescript
const phoneSchema = z.string()
  .regex(/^[\d\s\-+()]+$/, 'Invalid phone number format')
```

**原理**: 在字符類 `[]` 內部，`+`, `(`, `)` 這些字符失去了特殊意義，不需要轉義。

---

### 【BUG-FIX-2】應使用 const 而非 let

**位置**: `apps/api/src/features/scheduling/schemas/validation.ts:320`

**問題描述**:
變量 `startMinutes` 在定義後從未被重新賦值，應該使用 `const` 而不是 `let`，以提高代碼可讀性並符合 ESLint 的 `prefer-const` 規則。

**錯誤信息**:
```
320:7  error  'startMinutes' is never reassigned. Use 'const' instead  prefer-const
```

**修復前**:
```typescript
let startMinutes = startHour * 60 + startMin
let endMinutes = endHour * 60 + endMin

// Handle overnight shifts
if (endMinutes <= startMinutes) {
  endMinutes += 24 * 60
}
```

**修復後**:
```typescript
const startMinutes = startHour * 60 + startMin
let endMinutes = endHour * 60 + endMin

// Handle overnight shifts
if (endMinutes <= startMinutes) {
  endMinutes += 24 * 60
}
```

**原理**: `startMinutes` 只被賦值一次，使用 `const` 更明確表達不可變性。`endMinutes` 因為會被重新賦值（line 325），所以保持 `let`。
